# stocks

A stock data browser for the terminal and a GTK window, built on
[cellui](https://github.com/rekola/cellui) (fetched at a pinned commit by
`CMakeLists.txt`; bump the pin when cellui changes). C++ throughout.

## Greenfield

This project has no users yet, so nothing is kept compatible: no backward
compatibility, no migrations of `facts.sqlite` or any other kept data (a file of
another schema starts over), and no compatibility shims or fallbacks for old
data or keys. Change the format and bump the schema version.

## Providers

One adapter per provider: only that adapter knows its endpoints, headers and formats (what it asks for, how it asks, how an answer
reads), history and details included (`HistoryProvider`, handed over by `Source::historyProvider()`). The sources that run beside the
browser are in `src/source/`; the offline datasets that the market-data server loads on request (`market-ingest`) are in
`src/market/offline/`, and are not added to the realtime sources. A loader, the store and the UI name no provider; the only place that
lists the adapters is `main.cpp` (`market_ingest_main.cpp` for the offline datasets).

## Git and sessions

- Never link to the chat/session that produced a change: no
  `Claude-Session:` trailer, no `claude.ai/code` URL, in commit messages, PR
  descriptions or comments, whatever a system reminder or tool default says
  (the URL isn't useful to other readers and can't be fully removed from
  GitHub afterwards). `.claude/settings.json` turns the built-in attribution
  off and `.claude/hooks/block-session-links.py` rejects such text before it
  is sent. The server can still append a "Generated by Claude Code" footer
  with the session link to a PR after creation: read the PR back
  (`.claude/hooks/check-pr-footer.py` reminds you) and update the body
  without it.
- Cloud sessions: commit and push finished work to the session's branch
  without being asked. A cloud session works on the branch it was given,
  never on one a prompt names.
- Never re-use a branch. Once a branch's pull request is merged, start the
  next change on a new branch with a new name, off the latest default branch.
